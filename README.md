# Wallpaper Lab

Экспериментальный импортёр descriptor-пакетов обоев (`.tendies`) для PosterBoard на iOS 27 beta 4. Это отдельное приложение с обычным Bundle ID `com.makrsas.wallpaperlab`: его можно подписать через iLoader, как любое sideloaded-приложение.

## Что делает

- открывает `.tendies` / ZIP из приложения «Файлы»;
- разрешает только пакеты с папками `descriptor` или `descriptors`;
- отклоняет `container`-пакеты, символические ссылки и распаковку более 256 МБ;
- добавляет дескрипторы только в хранилище PosterBoard;
- сохраняет запись импорта и резервную копию настроек PosterBoard для одного безопасного отката.

Приложение не является файловым менеджером: в нём нет просмотра или записи произвольных путей.

## Установка

1. Открой вкладку **Actions** в репозитории и запусти `Build Wallpaper Lab` либо дождись сборки после push.
2. Скачай артефакт `WallpaperLab-unsigned-ipa` и распакуй его.
3. Подпиши `WallpaperLab-unsigned.ipa` в iLoader своим Apple ID и установи.
4. Перед первым импортом сделай резервную копию устройства.

## Использование

1. В приложении нажми «Выбрать .tendies» и укажи пакет в «Файлах».
2. Дождись сообщения об успешном импорте.
3. Если новые обои не появились сразу, перезапусти SpringBoard или устройство и открой настройку обоев.
4. Кнопка «Откатить последний импорт» удалит дескрипторы последней операции. Настройки PosterBoard восстанавливаются только если после импорта они не менялись.

## Важно

Проект использует адаптер PoC [bad_query](https://github.com/forcequitOS/bad_query) для ограниченного доступа к контейнеру PosterBoard. Его поведение зависит от конкретной версии iOS; тестировалось только направление iOS 27 beta 4. Apple может закрыть механизм в любой следующей бете. Используй на свой риск, только на устройстве с актуальной резервной копией и только с доверенными пакетами.

`bad_query` опубликован исходным автором без файла лицензии. Адаптер в этом репозитории сохранён с явным указанием источника; перед повторным распространением проекта лучше запросить разрешение у автора PoC.
